メシナビ プライバシーポリシー

制定日：2026年8月30日

Kosugi Hayate（以下「当方」）は、メシナビ（以下「本アプリ」）における利用者の情報の取り扱いについて、以下のとおり定めます。

1. 取得する情報

情報取得のタイミング利用目的

2. 情報の保存場所

取得した情報は、Google LLC が提供する Firebase（Authentication / Cloud Firestore / Cloud Functions / Cloud Messaging）に保存されます。データの保存リージョンは日本（東京）です。

3. クックアイ（AI解析）における画像の取り扱い

本アプリの中心的な機能であるため、特に詳しく説明します。

  1. 利用者が撮影した画像は、当方のサーバー（Cloud Functions）を経由して、Google LLC の生成 AI サービス（Gemini API）に送信されます。
  2. 当方は、送信された画像を保存しません。解析が終わった時点で画像はサーバーから破棄されます。
  3. サーバーに記録されるのは、解析結果として認識された品目名と分量のみです（「違う提案」を再度受け取るために必要なため）。この記録は24時間後に自動的に削除されます。
  4. Google における画像の取り扱いは、同社の Gemini API 追加利用規約に従います。当方は有料版の API を利用しており、送信されたデータが Google の生成 AI モデルの改善・学習に利用されることはありません。
  5. 他人の顔や、個人を特定できる情報が写り込んだ画像の送信はお控えください。

4. 広告について

  1. 本アプリは、無料でご利用の場合に Google AdMob による広告を表示します。プロプランをご契約中は広告を表示しません。
  2. 広告配信のため、Google および広告配信事業者が、端末の広告識別子（IDFA）やおおまかな位置情報等を取得する場合があります。
  3. iOS の「トラッキングの許可」を求めるダイアログで「Appにトラッキングしないように要求」を選択された場合、IDFA は取得されず、広告はパーソナライズされないものになります。この設定は、iOS の「設定」→「プライバシーとセキュリティ」→「トラッキング」からいつでも変更できます。
  4. Google による広告データの取り扱いについては、 Google のパートナーサイトにおけるデータ使用をご確認ください。

5. 第三者への提供

当方は、次の場合を除き、取得した情報を第三者に提供しません。

  • 利用者の同意がある場合
  • 法令に基づく場合
  • 本アプリの提供に必要な範囲で、以下の事業者に取り扱いを委託する場合
事業者提供する情報目的
Google LLC（Firebase）アカウント情報、プロフィール、利用回数、通知トークン認証・データ保存・通知配信
Google LLC（Gemini API）クックアイに使用する画像AI による解析
Google LLC（AdMob）広告識別子等広告の配信・効果測定
RevenueCat, Inc.購入情報、アカウント IDサブスクリプション状態の管理
Apple Inc.購入情報App 内課金の処理

6. 保存期間と削除

  1. アカウントに紐づく情報は、アカウントが存在する間、保存されます。
  2. クックアイの解析セッション（品目名・分量）は 24 時間後に自動削除されます。
  3. 広告視聴の記録は 7 日後に自動削除されます。
  4. アプリ内の「マイページ」→「アカウント設定」→「アカウント削除」を実行すると、クラウドに保存された利用者のデータは削除されます。削除したデータは復元できません。

7. 利用者の権利

利用者は、当方が保有する自身の情報について、開示・訂正・利用停止・削除を求めることができます。ご希望の場合は末尾の連絡先までご連絡ください。ご本人であることを確認のうえ、合理的な期間内に対応します。

8. お子様の利用について

本アプリは 13 歳未満の方を対象としていません。13 歳未満の方が本アプリを利用される場合は、保護者の方の同意と管理のもとでご利用ください。

9. 本ポリシーの変更

当方は本ポリシーを変更することがあります。重要な変更を行う場合は、アプリ内のお知らせまたは本ページへの掲載により周知します。
